# 01 — Next month's trends (predictive list)

**Format:** 3 fast picks with a confident tone. Reusable monthly.

## Title (pick one)
- `3 trends I'm calling for [MONTH] before they blow up`
- `[MONTH] trend predictions — save this and check back in 30 days`
- `Calling it: these 3 are about to be everywhere`

## 30-second beat sheet

| Time | What's happening | What you say |
|---|---|---|
| 0–3s | **Hook.** Tight close-up, direct to camera. Bold on-screen text: `I called [LAST TREND] a month early.` | "I called [LAST TREND] a month before it blew up. Here's what's next." |
| 3–6s | Cut to medium shot. On-screen: `3 picks for [MONTH]:` | "Three picks for [MONTH]." |
| 6–13s | **Pick 1.** Show the trend (image/clip in the corner). On-screen: `1. [TREND 1]` | "[TREND 1]. Up [N]% on [PLATFORM] this week. Why it pops: [one-sentence reason]." |
| 13–20s | **Pick 2.** On-screen: `2. [TREND 2]` | "[TREND 2]. Quietly seeded by [niche/community]. About to spill mainstream." |
| 20–26s | **Pick 3.** On-screen: `3. [TREND 3]` | "[TREND 3]. Almost no one is talking about it. Yet." |
| 26–30s | Cut back to face. On-screen: `Save this. Follow.` | "Save this short. Check back in 30 days. Follow for the receipts." |

## Visual notes
- Stand-up shot, dynamic. Cut every 2–3 seconds.
- For each pick, show a 1-second clip or screenshot in the upper-right corner.
- Big, sans-serif on-screen captions in white with a black outline. CapCut "Bold" preset works.

## Description template

```
3 trends I'm calling for [MONTH]. Save this and check back in 30 days.

1. [TREND 1] — [reason]
2. [TREND 2] — [reason]
3. [TREND 3] — [reason]

Which one are you betting on? Comment 1, 2, or 3.

#shorts #trending #trendforecast #[niche] #fyp
```
