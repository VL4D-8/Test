# Trendiest — Shorts scripts

Five ready-to-shoot scripts. Each one is a complete 30-second short: hook, beat sheet, on-screen text, voiceover, caption template, hashtags. Fill in the bracketed `[placeholders]` with the actual trend you're covering that day.

## How to actually make the videos

You can't just upload these — they're scripts. Pick whichever production path fits.

### Path A — Phone-and-face (fastest, most monetizable)
- iPhone or Android, vertical 9:16, front camera in good light.
- Clip a $15 lavalier mic to your shirt for clean audio.
- Edit in **CapCut** (free, mobile or desktop) — auto-captions, fast cuts, music.
- 30–60 min from idea to upload once you have a rhythm.

### Path B — Faceless (no on-camera, AI voiceover + B-roll)
- Voiceover: **ElevenLabs** (free tier, ~10k chars/month) — record the script, download MP3.
- B-roll: **Pexels** or **Pixabay** (free stock vertical clips). Search the topic + "vertical."
- Captions: **CapCut** auto-captions, or **Veed** / **Submagic** for fancier styles.
- Music: YouTube Audio Library (free, monetizable).
- 20–40 min per video.

### Path C — AI avatar (slower iteration but no recording)
- **HeyGen** or **Synthesia** — paste the script, pick an avatar, render.
- Add B-roll cutaways in CapCut to keep it dynamic.
- Note: monetization rules around AI-generated content evolve — disclose AI use in the description and avoid synthetic likenesses of real people.

## Posting cadence

For "Trendiest" specifically: **post daily** for the first 90 days. The channel name promises freshness; the algorithm rewards consistency. Better to ship a 7/10 short today than a 9/10 short next week.
