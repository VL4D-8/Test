# Trendiest — brand assets

Source files for the channel banner and avatar, plus a one-click PNG exporter.

## Files

- `banner.svg` — 2560×1440 channel banner. Black/red gradient with the "TRENDIEST" wordmark, "TRENDING NOW" pill, and rising-arrow accents.
- `avatar.svg` — 800×800 avatar. Circle-safe; displays a hot-gradient "T" with "TRENDIEST" wordmark beneath.
- `export.html` — open in a browser to preview both and download as PNG ready for YouTube.

## Quickest path to upload

1. Open `export.html` in any browser (or visit it via the same hosting URL you used for the app).
2. Click **Download PNG** under each asset.
3. Go to `studio.youtube.com` → **Customization** → **Branding**.
4. Upload `trendiest-avatar.png` as the Picture, `trendiest-banner.png` as the Banner.
5. Click **Publish** in the top right.

## Editing

Both files are plain SVG. Open in any text editor or design tool (Figma, Illustrator, Inkscape).

Common tweaks:
- Change the gradient colors → look for `#FF1F62` (pink) and `#FF6A1A` (orange) in either file.
- Change the tagline → `banner.svg`, search for `60-second drops`.
- Change the wordmark below the avatar → `avatar.svg`, search for `TRENDIEST`.

After editing, reload `export.html` and re-download the PNG.
